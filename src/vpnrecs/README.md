## 先选下一步

- **想少花钱，先按月试**：[看套餐对比表](#按预算快速筛选)，先找明确能按月付的档位，再点名称核对价格和流量。年付折算价不是月付价。
- **偶尔用，想找不限时**：先看表里的「不限时套餐」一列。点进详情再[核对付款与流量条件](#付款前核对这四项)，重点看是否仍在售、流量用完怎么算、账号是否有有效期。
- **已有订阅，直接导入**：[按设备打开安装与导入教程](#选好后按设备开始)，不用再翻套餐表。

## 付款前核对这四项

1. **一次实际支付多少**：区分月付金额与年付折算月价。标为“每月”的价格不一定可以按月付款，先确认付款周期、实付总额与续费条件。
2. **流量何时重置或到期**：年付套餐可能每月重置，也可能整年共用总流量；“不限时”仍需核对流量用尽、账号有效期及服务条款，不能理解为永久服务。
3. **你的客户端能否导入**：“通用订阅”不等于所有客户端、所有版本都兼容。购买前核对服务商提供的格式，以及自己设备上的客户端版本。
4. **能否先试及如何退出**：查看试用范围、退款条件和限制，再决定是否付款。资料价格、历史测试与提供方截图都不能保证你当前网络的实际体验。
