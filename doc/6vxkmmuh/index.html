macOS ClashVergeRev 安装与使用指南

emz2025/1/29大约 7 分钟翻墙科学上网ClashmacOSMac

内容基准与时效说明：本教程内容、适用版本与安全提醒以二毛主站为基准。软件界面可能随版本变化，下载时应优先核验官方项目地址和文件签名。

主站原文：https://www.ermao.net/article/6vxkmmuh/

Clash Verge Rev 是一款高效的代理工具，专为 macOS 用户打造，兼容 M 芯片和 Intel 芯片。本文将为您详细介绍如何在 macOS 上安装和配置 Clash Verge Rev，帮助您顺利开始使用。

1. 下载与安装

选择版本：

先在苹果菜单的“关于本机”中确认系统版本和芯片。官方安装说明当前要求 macOS 12 及以上；本教程不覆盖旧系统替换内核等兼容方案。

  • 官方发布（优先）：Clash Verge Rev GitHub Releases。官方目前仅通过 GitHub Releases 发布。选择正式版的 .dmg：Intel 芯片选 x64，Apple 芯片（M 系列）选 aarch64，并核对发布说明。
  • 本站镜像，非官方发布渠道：Intel x64 镜像、Apple Silicon 镜像。镜像可能晚于官方更新，不能仅凭文件名判断版本或真实性；需要确认来源时优先回到官方发布页。

安装过程：

  1. 核对下载来源、版本和架构后，双击打开 .dmg 文件。
  2. 若出现安全警告，先阅读完整提示，不要把所有警告都当作同一种安装障碍。对于“无法验证开发者”或“Apple 无法检查是否包含恶意软件”，先核对官方来源与发布说明；来源不明或无法确认时，停止安装并联系开发者。Apple 提醒，覆盖安全设置存在风险，不能据此认定应用安全。
  3. 只有在理解风险并自行决定信任该应用时，才参考 Apple 官方说明处理单个应用的例外：新版 macOS 的入口是“系统设置” > “隐私与安全性” > “安全性”；macOS 12 等旧版使用“系统偏好设置” > “安全性与隐私” > “通用”。按钮名称和是否显示以系统版本及具体警告为准。
  4. 如果提示应用会损坏电脑、含恶意软件或已损坏，不要套用上述例外步骤强行打开；停止使用该文件，按 Apple 提示处理并向开发者核实。不要关闭整体安全保护或执行移除隔离属性的命令来绕过警告。

完成安装：

  1. 将 Clash Verge Rev 拖动到“应用程序”文件夹中。
  2. 安装完成后，您可以从“应用程序”文件夹启动 Clash Verge Rev。

2. 基本设置

添加订阅链接：

如果没有订阅链接，可以参考这篇文章：https://www.ermao.net/posts/vpn。

  1. 打开 Clash Verge Rev 软件，点击顶部菜单栏中的“订阅”选项。
  2. 在订阅页面，将复制好的订阅地址粘贴到“订阅文件链接”框内，并点击“导入”。
  3. 等待导入完成。如果导入失败，尝试刷新页面并获取新的订阅地址。

注意：如果套餐已过期或订阅地址失效，导入可能会失败，请确保链接有效。

选择代理节点：

  1. 订阅导入成功后，点击软件中的“代理”选项。
  2. 在主界面左侧的“代理”栏中，您将看到通过订阅导入的服务器列表。
  3. 点击“手动选择节点”并选择您需要使用的节点。

说明：默认情况下，您无需修改其他设置，只需选择所需的代理节点即可。

3. 代理模式说明

  • 规则模式：根据预设的规则，决定哪些流量通过代理。
  • 全局模式：所有流量都通过代理。请注意，开启全局模式可能会导致国内网络的速度变慢，建议仅在必要时使用。
  • 直连模式：所有网络流量不通过代理，直接访问。

4. 系统代理设置

系统代理适合浏览器等遵循系统代理设置的应用，并不能保证接管所有应用。需要处理不支持系统代理的程序时，可按官方教程了解并配置 TUN 模式。流量是否经代理节点转发，还取决于规则、全局或直连模式及具体配置，详见官方术语说明。

  1. 先导入订阅、选择节点和路由模式；浏览器等常见需求可先在“设置”中开启“系统代理”。遵循系统代理设置的应用会把相应请求交给客户端处理。
  2. 需要接管不支持系统代理的程序时，再按官方入门说明配置 TUN，并核对其服务与授权要求。被接管的流量最终走代理节点还是直连，仍取决于路由模式和配置规则。

不需要把系统代理与 TUN 都开启作为完成配置的条件，也不要把二者概括为所有配置下绝对互斥。每次只调整一项，记录原设置，并在目标应用中验证结果。

节点延迟测试成功不等于目标应用实际连通，也不证明流媒体解锁。请实际打开需要使用的网站或应用，按其真实结果判断。

停止使用时，先关闭自己启用的系统代理和 TUN，再正常退出。若异常退出后网络异常，检查系统是否仍在使用本次配置的代理，只恢复更改前记录的设置；受管理设备先联系管理员，不要盲目清除单位代理或修改安全配置。

5. 问题排查

  • 导入订阅失败：如果在导入订阅时提示“链接无效”或“无法连接”，请确保订阅链接正确，并检查网络连接是否正常。
  • Clash Verge Rev 无效：若软件无法正常工作，尝试重启应用或重新设置系统代理。

6. 卸载 Clash Verge Rev

如果您需要卸载 Clash Verge Rev，可以按以下步骤操作：

  1. 先关闭系统代理和 TUN 模式，再退出 Clash Verge Rev。
  2. 如果安装过服务，请先按官方 macOS 卸载说明停止并移除服务，再删除应用。
  3. 打开“应用程序”文件夹，找到 Clash Verge Rev 应用图标，右键点击并选择“移到废纸篓”。
  4. 配置和订阅数据是否保留，应单独决定；需要删除时，请先确认已备份所需数据，再按官方说明处理对应目录。

以上就是在 macOS 上安装和配置 Clash Verge Rev 的完整步骤，按照这些简单的指导，您可以快速开始使用这一高效的代理工具。如果有任何问题，请随时查阅官方教程或联系我们获取更多帮助！
